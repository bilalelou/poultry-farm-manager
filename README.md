# 🐔 دجاجتي - تطبيق إدارة مزارع الدواجن وإنتاج البيض (Poultry Farm Management System)

تطبيق ويب متكامل واحترافي (PWA) مخصص لإدارة مشاريع تربية الدجاج لإنتاج البيض وتسيير الفقاسة بدقة واحترافية، يغطي الدورة الكاملة للمشروع من وضع البيضة في الفقاسة (اليوم 0) حتى بلوغ القطيع الشهر الخامس وبداية الإنتاج، وصولاً إلى المحاسبة التشغيلية وخطط التوسع المستقبلية.

---

## 🌟 الميزات الرئيسية (Core Features)

### 1. 📊 لوحة القيادة ومؤشرات الأداء (Dashboard & KPIs)
- **بطاقات المؤشرات الحية:** إجمالي المداخيل، إجمالي المصاريف، صافي الربح، هامش الربح (%)، تكلفة إنتاج البيضة الواحدة، عدد الدجاج النشط، ونسبة الإنتاج اليومي.
- **نقطة التعادل (Break-even Point):** حساب عدد البيض المتبقي لاسترداد رأس المال التأسيسي.
- **أشرطة الأهداف والمقارنة:** مؤشرات لونية تلقائية (أخضر، أصفر، أحمر) لمقارنة الإنتاج الفعلي بالأهداف المعيارية.
- **رسوم بيانية تفاعلية:** مقارنة شهرية للمداخيل والمصاريف، منحنى نسبة إنتاج البيض، ودائرة توزيع فئات المصاريف (Recharts).
- **إجراءات سريعة (Quick Actions):** تسجيل جمع البيض أو إضافة مصروف في ثوانٍ.

### 2. 🥚 تسيير الفقاسة ودورات التفقيس (Incubator Manager)
- إدارة دفعات الفقاسة مع شريط زمني حي يحسب اليوم الحالي من أصل 21 يوماً.
- التوجيه البيئي القياسي: متابعة درجات الحرارة والرطوبة وحالة التقليب لكل مرحلة (الأيام 1-18 مقابل 19-21).
- نقاط فحص تلقائية: الفحص الضوئي (اليوم 7) واحتساب نسبة الإخصاب، إيقاف التقليب (اليوم 18)، وتسجيل الفقس (اليوم 21).
- الحساب المالي لتكلفة الكتكوت الواحد وزر تحويل مباشر لمرحلة التربية.

### 3. 🐥 تتبع النمو والتربية (Rearing Tracker: Week 1 to 20)
- تتبع أسبوعي دقيق من الأسبوع 1 إلى الأسبوع 20.
- تحديد تلقائي للمرحلة الغذائية (بادي: 1-6، نامي: 7-18، ما قبل البيض: 19-20).
- مراقبة استهلاك العلف، النفوق التراكمي، مصاريف التدفئة، الإضاءة، والفرشة.
- جدول تحصينات مدمج للتذكير الأسبوعي بكل لقاح وطريقة إعطائه.
- فرز ومبيعات الذكور وخصم عائداتها تلقائياً من تكلفة الدفعة.
- ملخص الشهر الخامس: صافي تكلفة الدجاجة الجاهزة للإنتاج، ومقارنتها بسعر السوق لإظهار مقدار التوفير المالي، وزر النقل للقطيع البياض.

### 4. 🥚 الإنتاج اليومي للبيض والمبيعات (Daily Production & Sales)
- تسجيل الإنتاج اليومي: إجمالي البيض المجموع، التالف/المكسور، المحجوز للفقاسة، والاستهلاك الشخصي.
- حساب تلقائي لصافي البيض الصالح للبيع ونسبة الإنتاج اليومية.
- إدارة المبيعات بالوحدة أو الصينية (30 بيضة) بمختلف الفئات (بيض مائدة، بيض مخصب، كتاكيت، دجاج مستبعد، أسمدة).

### 5. 💰 المصاريف والتدفق النقدي (Expenses & Cash Flow)
- تصنيف المصاريف حسب النطاق (عام، مرتبط بدفعة، تأسيسي) والنوع (تشغيلي، رأسمالي) والفئة (علف، أدوية، كهرباء، إلخ).
- كشف التدفق النقدي الشهري (Monthly Cash Flow) لمقارنة المداخيل والمصاريف وصافي الرصيد التراكمي.

### 6. 📈 محاكي خطة التوسع (Flock Expansion Planner)
- أداة تخطيط ديناميكية تمتد من 12 إلى 24 شهراً.
- محاكاة دقيقة لنمو القطيع ومساحة العنبر المطلوبة (م²) واستهلاك العلف الشهري والإيرادات المتوقعة.
- **مؤشر التمويل الذاتي (Self-Financing Indicator):** يوضح تلقائياً إن كانت الأرباح المتراكمة تغطي تربية الدفعات الجديدة أم يلزم تمويل خارجي.

### 7. ⚙️ الإعدادات والفرضيات (Settings & Backup)
- تخصيص كامل لكافة الثوابت: سعة الفقاسة، أسعار الأعلاف، أسعار البيع، نسب الأهداف، وكثافة التربية.
- تصدير واستيراد نسخة احتياطية كاملة بصيغة JSON.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** [Next.js 16](https://nextjs.org/) (App Router) + [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/) + RTL Support + Arabic Font (Cairo)
- **Local Database:** [Dexie.js](https://dexie.org/) (IndexedDB wrapper) للعمل بدون إنترنت وحفظ البيانات محلياً على المتصفح
- **Charts:** [Recharts](https://recharts.org/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 التشغيل والتثبيت (Getting Started)

### المتطلبات الأساسية
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn أو pnpm

### خطوات التثبيت:

1. **استنساخ المستودع (Clone the repo):**
```bash
git clone https://github.com/<USERNAME>/<REPO_NAME>.git
cd <REPO_NAME>
```

2. **تثبيت الحزم (Install dependencies):**
```bash
npm install
```

3. **تشغيل خادم التطوير (Run development server):**
```bash
npm run dev
```

4. **فتح التطبيق في المتصفح:**
اذهب إلى `http://localhost:3000`
